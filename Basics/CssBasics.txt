Componentes Básicos da Linguagem CSS
O CSS (Cascading Style Sheets) é a linguagem de estilo usada para descrever a apresentação de documentos HTML . Diferente do HTML (marcação) e do Vue (framework), o CSS é uma linguagem de folha de estilos baseada em regras. Seus componentes fundamentais são:

1. Estrutura de uma Regra CSS
Uma regra CSS é composta por seletor + bloco de declarações .

css
seletor {
  propriedade: valor;
  outra-propriedade: valor;
}
Componente	Descrição
Seletor	Aponta para o(s) elemento(s) HTML que serão estilizados
Declaração	Par propriedade: valor
Propriedade	Característica a ser alterada (ex.: color, margin)
Valor	O que será aplicado à propriedade (ex.: red, 10px)
Bloco	Conjunto de declarações entre { }
css
p {
  color: blue;
  font-size: 16px;
}
2. Formas de Aplicar CSS
Forma	Descrição
Inline	Direto no atributo style do elemento HTML
Interno	Dentro da tag <style> no <head>
Externo	Arquivo .css vinculado via <link> (forma recomendada)
html
<!-- Inline -->
<p style="color: red;">Texto</p>

<!-- Interno -->
<style> p { color: red; } </style>

<!-- Externo -->
<link rel="stylesheet" href="style.css">
3. Tipos de Seletores
🔹 Seletores Simples
Seletor	Exemplo	Descrição
Tipo (tag)	p	Todos os <p>
Classe	.destaque	Elementos com class="destaque"
ID	#header	Elemento com id="header"
Universal	*	Todos os elementos
Atributo	[type="text"]	Elementos com atributo específico
🔹 Seletores Combinadores
Combinador	Exemplo	Descrição
Descendente	div p	<p> dentro de <div> (qualquer nível)
Filho direto	div > p	<p> filho direto de <div>
Irmão adjacente	h1 + p	<p> logo após <h1>
Irmão geral	h1 ~ p	Todos os <p> após <h1>
🔹 Pseudo-classes e Pseudo-elementos
Seletor	Descrição
:hover	Quando o mouse está sobre o elemento
:focus	Quando o elemento está focado
:first-child, :last-child	Posição entre irmãos
:nth-child(n)	Enésimo filho
:not(seletor)	Negação
::before, ::after	Conteúdo inserido antes/depois
::first-line, ::first-letter	Primeira linha/letra
4. Cascata, Especificidade e Herança
São os três pilares que definem qual estilo será aplicado .

Conceito	Descrição
Cascata	Ordem de aplicação: última regra vence (em empate)
Especificidade	Peso do seletor: inline > ID > classe > tag
Herança	Algumas propriedades são herdadas dos pais (color, font)
!important	Força uma declaração a vencer (usar com cautela)
Ordem de especificidade (do maior para o menor):

text
!important > inline > #id > .classe > tag > *
5. O Modelo de Caixa (Box Model)
Todo elemento HTML é uma caixa retangular composta por 4 camadas .

text
┌─────────────────────────────┐
│         Margin              │
│  ┌───────────────────────┐  │
│  │       Border          │  │
│  │  ┌─────────────────┐  │  │
│  │  │    Padding      │  │  │
│  │  │  ┌───────────┐  │  │  │
│  │  │  │ Conteúdo  │  │  │  │
│  │  │  └───────────┘  │  │  │
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
Camada	Descrição
Content	O conteúdo real (texto, imagem)
Padding	Espaço interno entre conteúdo e borda
Border	Borda ao redor do padding
Margin	Espaço externo entre elementos
box-sizing: border-box; faz com que width/height incluam padding e border.

6. Unidades de Medida
🔹 Absolutas
Unidade	Descrição
px	Pixels
cm, mm, in	Centímetros, milímetros, polegadas
pt, pc	Pontos, paicas
🔹 Relativas
Unidade	Relativa a
%	Ao elemento pai
em	Ao tamanho da fonte do elemento
rem	Ao tamanho da fonte do <html>
vw, vh	1% da largura/altura da viewport
vmin, vmax	Menor/maior entre vw e vh
ch, ex	Largura de caractere / altura-x
🔹 Cores
Formato	Exemplo
Nome	red, blue
Hexadecimal	#ff0000, #f00
RGB / RGBA	rgb(255,0,0), rgba(255,0,0,0.5)
HSL / HSLA	hsl(0,100%,50%), hsla(0,100%,50%,0.5)
7. Principais Categorias de Propriedades
📝 Texto e Fonte
color, font-family, font-size, font-weight, font-style, text-align, text-decoration, line-height, letter-spacing, text-transform

📦 Box Model
width, height, margin, padding, border, box-sizing, overflow

🎨 Cores e Fundo
background-color, background-image, background-position, background-size, background-repeat, opacity

📐 Layout
display, position, top/right/bottom/left, float, clear, z-index, flexbox, grid

✨ Efeitos
box-shadow, text-shadow, border-radius, transition, transform, animation, filter

8. Sistemas de Layout Modernos
🔹 Flexbox (unidimensional)
Ideal para alinhar itens em uma linha ou coluna .

css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 10px;
}
🔹 Grid (bidimensional)
Ideal para layouts complexos em linhas e colunas .

css
.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  gap: 20px;
}
🔹 Position
Valor	Descrição
static	Padrão, segue o fluxo
relative	Relativo à posição original
absolute	Relativo ao ancestral posicionado
fixed	Relativo à viewport
sticky	Híbrido entre relative e fixed
9. Media Queries (Responsividade)
Permitem aplicar estilos condicionalmente com base em características do dispositivo .

css
@media (max-width: 768px) {
  .container { flex-direction: column; }
}
Componente	Descrição
@media	Regra condicional
max-width / min-width	Largura máxima/mínima
orientation	Retrato ou paisagem
prefers-color-scheme	Tema claro/escuro
10. Variáveis CSS (Custom Properties)
Permitem armazenar valores reutilizáveis, com escopo e herança .

css
:root {
  --cor-primaria: #3498db;
  --espacamento: 16px;
}

button {
  background: var(--cor-primaria);
  padding: var(--espacamento);
}
11. Animações e Transições
Componente	Descrição
transition	Anima mudanças de propriedade suavemente
@keyframes	Define estágios de uma animação
animation	Aplica a animação a um elemento
transform	Translada, rotaciona, escala, inclina
css
@keyframes girar {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
.elemento {
  animation: girar 2s linear infinite;
}
12. Resumo dos Componentes-Chave
text
CSS = Seletores + Propriedades + Valores + Cascata
Componente	Descrição
Regra	Seletor + bloco de declarações
Seletor	Aponta para elementos HTML
Propriedade	Característica estilizada
Valor	O que é aplicado
Cascata	Ordem de prioridade das regras
Especificidade	Peso de cada seletor
Box Model	Content + padding + border + margin
Unidades	Absolutas (px) e relativas (rem, %, vw)
Media Queries	Estilos condicionais por dispositivo
Variáveis	Valores reutilizáveis (--nome)
Flexbox / Grid	Sistemas de layout modernos
