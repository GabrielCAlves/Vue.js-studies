Tutorial completo: criando um projeto Vue do zero com backend (registro, login e CRUD)
Este tutorial mostra como construir uma aplicação fullstack com Vue 3 no frontend e Node.js/Express no backend, incluindo registro de usuário, login e operações CRUD protegidas por autenticação. A stack escolhida é Vue 3 + Vite (recomendação oficial), Express + Prisma + SQLite (leve, sem precisar instalar servidor de banco separado) e JWT para autenticação.

Parte 1: Criando o projeto Vue (frontend)
O Vue 3 recomenda usar a ferramenta oficial create-vue, baseada no Vite, com hot reload e suporte a componentes de arquivo único.

1.1 Preparando o ambiente
Verifique se você tem Node.js 16+ (recomendado 18 ou 20) instalado. No terminal:

bash
node -v
npm -v
1.2 Criando o projeto
bash
npm create vue@latest vue-fullstack-demo
Durante a criação, serão feitas algumas perguntas. Para este tutorial, recomendo:

TypeScript: sim (opcional, o tutorial vai marcar diferenças entre JS e TS)

Vue Router: sim (para navegação entre páginas)

Pinia: sim (para gerenciar estado, como o token de login)

ESLint / Prettier: conforme sua preferência

Depois de criado, entre na pasta e instale as dependências:

bash
cd vue-fullstack-demo
npm install
npm run dev
Acesse http://localhost:5173 e você verá a página padrão do Vue.

1.3 Instalando o Axios
O Axios é o cliente HTTP mais usado no ecossistema Vue, e será usado para conversar com o backend.

bash
npm install axios
Parte 2: Montando o backend (API)
No backend usaremos o framework Express, o ORM Prisma, o banco SQLite (zero configuração) e JWT para autenticação.

2.1 Inicializando o projeto do backend
Fora da pasta do projeto Vue, crie uma pasta separada para o backend:

bash
mkdir vue-backend
cd vue-backend
npm init -y
Instale as dependências necessárias:

bash
npm install express cors bcryptjs jsonwebtoken @prisma/client
npm install -D prisma nodemon
express: framework web

cors: permite requisições do frontend em outra origem

bcryptjs: faz o hash das senhas

jsonwebtoken: gera e valida os tokens JWT

prisma / @prisma/client: ferramenta de banco e cliente

2.2 Configurando o Prisma e o modelo de dados
bash
npx prisma init --datasource-provider sqlite
Isso cria o arquivo prisma/schema.prisma e o arquivo .env. Edite schema.prisma e defina os modelos de usuário e tarefa:

prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "sqlite"
  url      = env("DATABASE_URL")
}

model User {
  id        Int      @id @default(autoincrement())
  email     String   @unique
  password  String
  name      String?
  createdAt DateTime @default(now())
  todos     Todo[]
}

model Todo {
  id          Int      @id @default(autoincrement())
  title       String
  description String?
  completed   Boolean  @default(false)
  userId      Int
  user        User     @relation(fields: [userId], references: [id])
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
}
No arquivo .env, defina o caminho do banco e a chave secreta do JWT:

text
DATABASE_URL="file:./dev.db"
JWT_SECRET="uma-chave-secreta-bem-segura-aqui"
Rode a migração para criar as tabelas no banco:

bash
npx prisma migrate dev --name init
2.3 Criando o servidor Express
Crie src/server.js dentro da pasta vue-backend:

javascript
const express = require('express');
const cors = require('cors');
const authRoutes = require('./routes/auth');
const todoRoutes = require('./routes/todos');
const { authenticateToken } = require('./middleware/auth');

const app = express();
const PORT = 3000;

app.use(cors());
app.use(express.json());

// Rotas públicas
app.use('/api/auth', authRoutes);

// Rotas protegidas (exigem JWT)
app.use('/api/todos', authenticateToken, todoRoutes);

app.listen(PORT, () => {
  console.log(`Servidor rodando em http://localhost:${PORT}`);
});
2.4 Middleware de autenticação
Crie src/middleware/auth.js:

javascript
const jwt = require('jsonwebtoken');

function authenticateToken(req, res, next) {
  const authHeader = req.headers['authorization'];
  const token = authHeader && authHeader.split(' ')[1]; // Bearer TOKEN

  if (!token) {
    return res.status(401).json({ error: 'Token não fornecido' });
  }

  jwt.verify(token, process.env.JWT_SECRET, (err, user) => {
    if (err) {
      return res.status(403).json({ error: 'Token inválido ou expirado' });
    }
    req.user = user;
    next();
  });
}

module.exports = { authenticateToken };
2.5 Rotas de registro e login
Crie src/routes/auth.js:

javascript
const express = require('express');
const bcrypt = require('bcryptjs');
const jwt = require('jsonwebtoken');
const { PrismaClient } = require('@prisma/client');

const router = express.Router();
const prisma = new PrismaClient();

// POST /api/auth/register
router.post('/register', async (req, res) => {
  try {
    const { email, password, name } = req.body;

    if (!email || !password) {
      return res.status(400).json({ error: 'Email e senha são obrigatórios' });
    }

    const existingUser = await prisma.user.findUnique({ where: { email } });
    if (existingUser) {
      return res.status(400).json({ error: 'Email já cadastrado' });
    }

    const hashedPassword = await bcrypt.hash(password, 10);

    const user = await prisma.user.create({
      data: { email, password: hashedPassword, name },
    });

    const token = jwt.sign(
      { userId: user.id, email: user.email },
      process.env.JWT_SECRET,
      { expiresIn: '7d' }
    );

    res.status(201).json({ token, user: { id: user.id, email: user.email, name: user.name } });
  } catch (error) {
    console.error(error);
    res.status(500).json({ error: 'Erro ao registrar usuário' });
  }
});

// POST /api/auth/login
router.post('/login', async (req, res) => {
  try {
    const { email, password } = req.body;

    if (!email || !password) {
      return res.status(400).json({ error: 'Email e senha são obrigatórios' });
    }

    const user = await prisma.user.findUnique({ where: { email } });
    if (!user) {
      return res.status(401).json({ error: 'Credenciais inválidas' });
    }

    const validPassword = await bcrypt.compare(password, user.password);
    if (!validPassword) {
      return res.status(401).json({ error: 'Credenciais inválidas' });
    }

    const token = jwt.sign(
      { userId: user.id, email: user.email },
      process.env.JWT_SECRET,
      { expiresIn: '7d' }
    );

    res.json({ token, user: { id: user.id, email: user.email, name: user.name } });
  } catch (error) {
    console.error(error);
    res.status(500).json({ error: 'Erro ao fazer login' });
  }
});

module.exports = router;
2.6 Rotas de CRUD (tarefas)
Crie src/routes/todos.js:

javascript
const express = require('express');
const { PrismaClient } = require('@prisma/client');

const router = express.Router();
const prisma = new PrismaClient();

// GET /api/todos - Lista todas as tarefas do usuário
router.get('/', async (req, res) => {
  const todos = await prisma.todo.findMany({
    where: { userId: req.user.userId },
    orderBy: { createdAt: 'desc' },
  });
  res.json(todos);
});

// POST /api/todos - Cria uma nova tarefa
router.post('/', async (req, res) => {
  const { title, description } = req.body;
  if (!title) {
    return res.status(400).json({ error: 'Título é obrigatório' });
  }
  const todo = await prisma.todo.create({
    data: { title, description, userId: req.user.userId },
  });
  res.status(201).json(todo);
});

// PUT /api/todos/:id - Atualiza uma tarefa
router.put('/:id', async (req, res) => {
  const { id } = req.params;
  const { title, description, completed } = req.body;

  const existing = await prisma.todo.findFirst({
    where: { id: parseInt(id), userId: req.user.userId },
  });
  if (!existing) {
    return res.status(404).json({ error: 'Tarefa não encontrada' });
  }

  const todo = await prisma.todo.update({
    where: { id: parseInt(id) },
    data: { title, description, completed },
  });
  res.json(todo);
});

// DELETE /api/todos/:id - Remove uma tarefa
router.delete('/:id', async (req, res) => {
  const { id } = req.params;

  const existing = await prisma.todo.findFirst({
    where: { id: parseInt(id), userId: req.user.userId },
  });
  if (!existing) {
    return res.status(404).json({ error: 'Tarefa não encontrada' });
  }

  await prisma.todo.delete({ where: { id: parseInt(id) } });
  res.status(204).send();
});

module.exports = router;

Parte 3: Conectando o Vue ao backend
3.1 Configurando a instância do Axios
Dentro de src, crie o arquivo api/client.js:

javascript
import axios from 'axios';

const apiClient = axios.create({
  baseURL: 'http://localhost:3000/api',
  headers: { 'Content-Type': 'application/json' },
});

// Interceptor de requisição: anexa o token automaticamente
apiClient.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

export default apiClient;
3.2 Criando a store de autenticação com Pinia
Em src/stores, crie auth.js:

javascript
import { defineStore } from 'pinia';
import { ref } from 'vue';
import apiClient from '@/api/client';

export const useAuthStore = defineStore('auth', () => {
  const user = ref(null);
  const token = ref(localStorage.getItem('token'));

  async function register(email, password, name) {
    const response = await apiClient.post('/auth/register', { email, password, name });
    token.value = response.data.token;
    user.value = response.data.user;
    localStorage.setItem('token', token.value);
  }

  async function login(email, password) {
    const response = await apiClient.post('/auth/login', { email, password });
    token.value = response.data.token;
    user.value = response.data.user;
    localStorage.setItem('token', token.value);
  }

  function logout() {
    token.value = null;
    user.value = null;
    localStorage.removeItem('token');
  }

  return { user, token, register, login, logout };
});
3.3 Componente de login/registro
Crie src/views/LoginView.vue:

vue
<script setup>
import { ref } from 'vue';
import { useRouter } from 'vue-router';
import { useAuthStore } from '@/stores/auth';

const router = useRouter();
const authStore = useAuthStore();

const isRegister = ref(false);
const email = ref('');
const password = ref('');
const name = ref('');
const error = ref('');

async function handleSubmit() {
  error.value = '';
  try {
    if (isRegister.value) {
      await authStore.register(email.value, password.value, name.value);
    } else {
      await authStore.login(email.value, password.value);
    }
    router.push('/todos');
  } catch (e) {
    error.value = e.response?.data?.error || 'Ocorreu um erro';
  }
}
</script>

<template>
  <div class="login-container">
    <h1>{{ isRegister ? 'Registrar' : 'Entrar' }}</h1>
    <form @submit.prevent="handleSubmit">
      <input v-if="isRegister" v-model="name" type="text" placeholder="Nome" required />
      <input v-model="email" type="email" placeholder="Email" required />
      <input v-model="password" type="password" placeholder="Senha" required />
      <button type="submit">{{ isRegister ? 'Criar conta' : 'Entrar' }}</button>
    </form>
    <p v-if="error" class="error">{{ error }}</p>
    <button @click="isRegister = !isRegister">
      {{ isRegister ? 'Já tem conta? Fazer login' : 'Não tem conta? Registrar' }}
    </button>
  </div>
</template>
3.4 Componente de CRUD
Crie src/views/TodosView.vue:

vue
<script setup>
import { ref, onMounted } from 'vue';
import { useRouter } from 'vue-router';
import { useAuthStore } from '@/stores/auth';
import apiClient from '@/api/client';

const router = useRouter();
const authStore = useAuthStore();

const todos = ref([]);
const newTitle = ref('');
const newDescription = ref('');
const editingId = ref(null);
const editTitle = ref('');
const editDescription = ref('');

onMounted(async () => {
  if (!authStore.token) {
    router.push('/login');
    return;
  }
  await loadTodos();
});

async function loadTodos() {
  const response = await apiClient.get('/todos');
  todos.value = response.data;
}

async function createTodo() {
  if (!newTitle.value.trim()) return;
  await apiClient.post('/todos', { title: newTitle.value, description: newDescription.value });
  newTitle.value = '';
  newDescription.value = '';
  await loadTodos();
}

function startEdit(todo) {
  editingId.value = todo.id;
  editTitle.value = todo.title;
  editDescription.value = todo.description || '';
}

async function saveEdit(id) {
  await apiClient.put(`/todos/${id}`, {
    title: editTitle.value,
    description: editDescription.value,
    completed: todos.value.find(t => t.id === id).completed,
  });
  editingId.value = null;
  await loadTodos();
}

async function toggleComplete(todo) {
  await apiClient.put(`/todos/${todo.id}`, {
    title: todo.title,
    description: todo.description,
    completed: !todo.completed,
  });
  await loadTodos();
}

async function deleteTodo(id) {
  await apiClient.delete(`/todos/${id}`);
  await loadTodos();
}

function logout() {
  authStore.logout();
  router.push('/login');
}
</script>

<template>
  <div class="todos-container">
    <header>
      <h1>Minhas tarefas</h1>
      <button @click="logout">Sair</button>
    </header>

    <div class="create-form">
      <input v-model="newTitle" placeholder="Título" />
      <input v-model="newDescription" placeholder="Descrição (opcional)" />
      <button @click="createTodo">Adicionar</button>
    </div>

    <ul>
      <li v-for="todo in todos" :key="todo.id" :class="{ completed: todo.completed }">
        <template v-if="editingId === todo.id">
          <input v-model="editTitle" />
          <input v-model="editDescription" />
          <button @click="saveEdit(todo.id)">Salvar</button>
          <button @click="editingId = null">Cancelar</button>
        </template>
        <template v-else>
          <input type="checkbox" :checked="todo.completed" @change="toggleComplete(todo)" />
          <span>{{ todo.title }}</span>
          <small>{{ todo.description }}</small>
          <button @click="startEdit(todo)">Editar</button>
          <button @click="deleteTodo(todo.id)">Excluir</button>
        </template>
      </li>
    </ul>
  </div>
</template>
3.5 Configurando as rotas
Edite src/router/index.js:

javascript
import { createRouter, createWebHistory } from 'vue-router';
import LoginView from '@/views/LoginView.vue';
import TodosView from '@/views/TodosView.vue';

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', redirect: '/login' },
    { path: '/login', component: LoginView },
    { path: '/todos', component: TodosView },
  ],

Executando e testando
Inicie o backend (na pasta vue-backend): npm run dev

Inicie o frontend (na pasta vue-fullstack-demo): npm run dev

Acesse http://localhost:5173, registre uma conta, faça login e comece a criar, editar, concluir e excluir tarefas.

Pontos importantes
Frontend: usa Vue 3 com <script setup>, Pinia, Vue Router e um interceptor do Axios que anexa o JWT automaticamente.

Backend: usa Express + Prisma + SQLite, com bcryptjs para hash de senha e jsonwebtoken para gerar/validar tokens.

Segurança: senhas nunca são salvas em texto puro; as rotas protegidas passam por middleware que valida o JWT; cada usuário só acessa os próprios dados.

Escalando: para trocar o SQLite por PostgreSQL ou MySQL, basta mudar o provider e a DATABASE_URL no schema.prisma; para publicar, rode npm run build no frontend e use PM2 ou Docker no backend.
