Componentes Básicos da Linguagem JavaScript
O JavaScript (JS) é uma linguagem de programação interpretada, dinâmica, multiparadigma e baseada em prototótipos, executada principalmente em navegadores e em ambientes como Node.js . Seus componentes fundamentais são:

1. Estrutura Básica
JavaScript não exige estrutura de documento como HTML, mas pode ser incluído de três formas :

html
<!-- Interno -->
<script>
  console.log('Olá, mundo!');
</script>

<!-- Externo -->
<script src="script.js"></script>

<!-- Inline (evento) -->
<button onclick="alert('Oi')">Clique</button>
Componente	Descrição
Instrução	Linha de comando (termina com ; opcional)
Bloco	Conjunto de instruções entre { }
Comentário	// linha ou /* bloco */
2. Tipos de Dados (Primitivos)
JavaScript possui 7 tipos primitivos e 1 tipo de referência (Object) .

Tipo	Exemplo	Descrição
string	"texto", 'texto', `texto`	Cadeia de caracteres
number	42, 3.14, NaN, Infinity	Números (inteiros e decimais)
bigint	9007199254740991n	Inteiros muito grandes
boolean	true, false	Verdadeiro ou falso
undefined	undefined	Valor não atribuído
null	null	Ausência intencional de valor
symbol	Symbol('id')	Identificador único
object	{}, [], function(){}	Referência (não primitivo)
3. Variáveis e Declarações
Palavra-chave	Escopo	Reatribuível	Hoisting
var	Função	Sim	Sim (inicializa undefined)
let	Bloco	Sim	Sim (TDZ — não inicializa)
const	Bloco	Não	Sim (TDZ — não inicializa)
js
var antigo = 'evite';
let mutavel = 'pode mudar';
const fixo = 'não muda';
Boas práticas: prefira const, use let quando precisar reatribuir, evite var .

4. Operadores
🔹 Aritméticos
+, -, *, /, % (resto), ** (exponenciação), ++, --

🔹 Atribuição
=, +=, -=, *=, /=, %=, **=

🔹 Comparação
== (igualdade flexível), === (igualdade estrita), !=, !==, >, <, >=, <=

Prefira sempre === e !== para evitar coerção de tipos.

🔹 Lógicos
&& (E), || (OU), ! (NÃO), ?? (nullish coalescing)

🔹 Outros
typeof, instanceof, in, delete, void, ?. (optional chaining), ... (spread/rest)

5. Estruturas de Controle
🔹 Condicionais
js
if (condicao) { ... }
else if (outra) { ... }
else { ... }

switch (valor) {
  case 1: ...; break;
  default: ...;
}
🔹 Laços (Loops)
Laço	Uso
for	Controle total (início, condição, incremento)
for...of	Itera valores de iteráveis (arrays, strings)
for...in	Itera chaves de objetos
while	Enquanto condição for verdadeira
do...while	Executa ao menos uma vez
js
for (let i = 0; i < 5; i++) { ... }
for (const item of array) { ... }
for (const chave in objeto) { ... }
🔹 Controle de Fluxo
break, continue, return, throw, try...catch...finally

6. Funções
🔹 Formas de Declarar
js
// Declaração
function soma(a, b) { return a + b; }

// Expressão
const soma = function(a, b) { return a + b; };

// Arrow function (ES6)
const soma = (a, b) => a + b;

// Método
const obj = { soma(a, b) { return a + b; } };
🔹 Características
Conceito	Descrição
Parâmetros	Entradas da função
Argumentos	Valores passados na chamada
return	Devolve valor (senão retorna undefined)
this	Contexto de execução (diferente em arrow functions)
Closure	Função que "lembra" do escopo onde foi criada
Hoisting	Declarações são elevadas ao topo do escopo
Rest/Spread	...args coleta ou espalha valores
7. Objetos
Estrutura de pares chave-valor .

js
const pessoa = {
  nome: 'Ana',
  idade: 30,
  saudar() { return `Olá, ${this.nome}`; }
};

// Acesso
pessoa.nome;        // notação de ponto
pessoa['idade'];    // notação de colchetes

// Desestruturação
const { nome, idade } = pessoa;

// Spread
const copia = { ...pessoa, cidade: 'SP' };
8. Arrays
Listas ordenadas de valores .

js
const frutas = ['maçã', 'banana', 'uva'];

frutas.length;          // 3
frutas[0];              // 'maçã'
frutas.push('pera');    // adiciona ao fim
frutas.pop();           // remove do fim
🔹 Métodos Principais
Método	Função
push / pop	Adiciona/remove no fim
unshift / shift	Adiciona/remove no início
map	Transforma cada item
filter	Filtra itens
reduce	Reduz a um único valor
forEach	Itera sem retornar
find / findIndex	Busca item/índice
some / every	Testa condição
sort / reverse	Ordena/inverte
slice / splice	Copia / modifica
includes	Verifica existência
join	Junta em string
9. Classes (ES6+)
Açúcar sintático sobre protótipos .

js
class Animal {
  constructor(nome) {
    this.nome = nome;
  }
  falar() {
    return `${this.nome} faz um som`;
  }
}

class Cachorro extends Animal {
  falar() {
    return `${this.nome} late`;
  }
}
Componente	Descrição
constructor	Método de inicialização
extends	Herança
super	Chama o pai
static	Método/propriedade da classe
get / set	Acessores
Campos privados	#atributo
10. Escopo e Hoisting
Tipo de Escopo	Descrição
Global	Fora de qualquer função
Função	Dentro de uma função (var)
Bloco	Dentro de { } (let, const)
Módulo	Dentro de um arquivo ES Module
Hoisting: declarações são movidas ao topo do escopo em tempo de compilação.

11. Assincronismo
JavaScript é single-threaded mas usa o event loop para tarefas assíncronas .

🔹 Formas de Lidar
Forma	Descrição
Callbacks	Funções passadas como argumento
Promises	Objeto com estados pending, fulfilled, rejected
async/await	Sintaxe que torna código assíncrono parecido com síncrono
js
// Promise
fetch('/api')
  .then(res => res.json())
  .then(dados => console.log(dados))
  .catch(erro => console.error(erro));

// Async/await
async function buscar() {
  try {
    const res = await fetch('/api');
    const dados = await res.json();
    console.log(dados);
  } catch (erro) {
    console.error(erro);
  }
}
🔹 Componentes do Assincronismo
Event Loop — Gerencia fila de tarefas

Microtasks — Promises (prioridade alta)

Macrotasks — setTimeout, eventos (prioridade baixa)

setTimeout / setInterval — Temporizadores

queueMicrotask — Agenda microtarefa

12. Módulos (ES Modules)
Permitem dividir código em arquivos reutilizáveis .

js
// math.js
export const PI = 3.14;
export function soma(a, b) { return a + b; }
export default function multiplica(a, b) { return a * b; }

// main.js
import multiplica, { PI, soma } from './math.js';
Componente	Descrição
export	Exporta valores
export default	Exportação padrão (uma por módulo)
import	Importa valores
import()	Importação dinâmica (retorna Promise)

14. Tratamento de Erros
js
try {
  throw new Error('Algo deu errado');
} catch (erro) {
  console.error(erro.message);
} finally {
  console.log('Sempre executa');
}
Componente	Descrição
try	Bloco monitorado
catch	Captura o erro
finally	Executa sempre
throw	Lança um erro
Error	Objeto base de erros
Tipos	TypeError, ReferenceError, SyntaxError, RangeError
15. Paradigmas Suportados
Paradigma	Descrição
Imperativo	Instruções passo a passo
Funcional	Funções puras, imutabilidade, map/filter/reduce
Orientado a Objetos	Classes, herança, encapsulamento
Baseado em Protótipos	Herança via __proto__ / Object.create
Assíncrono	Callbacks, Promises, async/await
Event-driven	Reage a eventos do DOM/servidor
16. Resumo dos Componentes-Chave
text
JavaScript = Valores + Variáveis + Operadores + Controle + Funções + Objetos + Assincronismo
Componente	Descrição
Tipos primitivos	string, number, boolean, null, undefined, bigint, symbol
Variáveis	var, let, const
Operadores	Aritméticos, lógicos, comparação, atribuição

Funções	Declaração, expressão, arrow, closures
Objetos	Pares chave-valor, desestruturação, spread
Arrays	Métodos como map, filter, reduce
