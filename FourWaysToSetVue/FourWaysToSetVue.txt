1. CDN Package
<script src="https://unpkg.com/vue@next"></script>
- incorporate Vue into a really old legacy code base or quickly prototype

2. npm 
nmp install vue@next
- Preferred approach over CDN when building large scale applications with Vue.
- is the recommended approach for building large scale applications with Vue.

3. Vue CLI
vue create <project-name>
- Vue provides an official CLI for quickly scaffolding single page applications
npm install -g @vue/CLI
- takes only a few minutes to get up and running with hot-reload, lint-on-save, and production-rady builds.

(
    npm install -g @vue/cli
    vue create reusable-components
    cd reusable-components
    npm run serve
)

4. Vite
npm init vite-app <project-name>
- An opinionated web dev build tool that serves your code via native ES Module imports
- Your code is served at a lightning fast speed and you get nearly instant hot module replacement
- its the most recent
